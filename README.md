## The game

A vaporwave fever dream in a pastel-neon checker plaza — now with the full
collection game: **37 brainrots** across 8 rarities, **8 dice** (one per
tier), **10 personal bases**, **Rebirth**, **random 60-second weather
events** that multiply sell values up to x12, a **6-tab mutation Index**,
a **🎒 Inventory panel** to choose which brainrots you hold, and two
shops in the plaza: the gold **Sell Zone** and the purple **Luck
Altar**. Max **10 players** per server — one base each. WalkSpeed is 26,
so crossing the big plaza feels fast.

- **The cast (37 characters, the viral Italian brainrot memes, built procedurally from Parts):**
  - **Common (8)** — Pipi Kiwi, Boneca Ambalabu, Pipi Popcorn, Pot
    Hotspot, Trippi Troppi, Los Crocodillitos, Trulimero Trulichina,
    Frulli Frulla ($10–$25).
  - **Uncommon (7)** — Lirili Larila, Bananita Dolphinita, Graipuss
    Medussi, Los Orcalitos, Zibra Zubra Zibralini, Il Cacto Hipopotamo,
    Karkerkar Kurkur ($60–$120).
  - **Rare (6)** — Chicletera Bicicleteira, Rhyno Toasterino,
    Tigrrullini Watermellini, Blueberrinni Octopussini, Svinino
    Bombondino, Orangutini Ananasini ($300–$600).
  - **Epic (5)** — Frigo Camelo, Giraffa Celeste, Bombombini Gusini, Los
    Tralaleritos, Las Tralaleritas ($1,500–$3,000).
  - **Legendary (4)** — Brr Brr Patapim, Chimpanzini Bananini,
    Cappuccino Assassino, Tung Tung Tung Sahur ($8,000–$20,000).
  - **Mythic (3)** — La Vaca Saturno Saturnita, Chef Crabracadabra,
    Tralalero Tralala ($60,000–$120,000).
  - **Secret (3)** — Ballerina Cappuccina, Cappuccino Ballerino, La
    Grande Combinazione ($300,000–$500,000).
  - **Godly (1)** — Bombardiro Crocodilo ($2,500,000).
- **Dice (8, north of the plaza):** one big die per tier — Common,
  Uncommon, Rare, Epic, Legendary, Mythic, Secret, Godly. A die only ever
  gives brainrots of its own tier. Hold E on a die (or press ROLL in the
  🎲 DICE panel) to roll it for **Aura**. Prices climb x10 per tier:
  100 / 1,000 / 10,000 / 100,000 / 1,000,000 / 10,000,000 /
  100,000,000 / 1,000,000,000 Aura. The physical die **tumbles
  visibly** — multi-axis spin, a 4-stud hop, a rarity glow, then a
  sparkle burst — and the result card shows the pull. The brainrot
  appears in your base **and** in your Roblox Backpack as a Tool.
- **Backpack Tools:** every copy you own is a Tool named "Name • RARITY"
  in your Roblox Backpack — press **1, 2, 3…** (or tap the hotbar) to hold
  a brainrot in your hand. Selling a copy removes its Tool. Your Roblox
  Backpack holds every brainrot now. Open the **🎒 INVENTORY** panel
  (v7.4) to choose which brainrots are **HELD** (Tools in your hotbar)
  and which are **STORED** (inventory only, freeing hotbar slots) —
  copies, base display and income are untouched either way.
- **Personal bases (10):** every player gets one base (5 west, 5 east of
  the plaza) with **10 pedestal slots** (2×5 grid, big pedestals). Only
  **4 slots are open at Rebirth 0**; each rebirth opens +1 (all 10 at
  Rebirth 6). Locked slots show a padlock + the Rebirth that opens them.
  The top 10 brainrots you own (by Aura/s) stand on the pedestals, **2x
  bigger** than before, slowly spinning, with a name + ×N copy badge.
  Every distinct brainrot you own pays passive Aura every second by
  rarity (Common 5/s … Godly 100,000/s) — even one without a pedestal.
  An 11th player gets no base but can still play (their collection still
  earns, and their Tools still work).
- **Steal & Defend (v7.3):** hold **E** on a brainrot in an enemy base to
  steal it (only if that base isn't locked), carry it home on your head,
  and step into your own base to keep it. Lock your own base for 30s with
  the 🔒 LOCK button or the **L** key (60s cooldown) — a locked base shows
  a red shield wall + LOCKED sign. Dying or leaving while carrying returns
  the brainrot to its owner, so nothing is ever lost to a crash.
- **Rebirth (centre altar):** Rebirth 0 opens only the Common dice. Each
  rebirth unlocks the next dice tier (Rebirth 1 = Uncommon … Rebirth 7 =
  Godly), opens **+1 base slot**, and adds a permanent **+50% Aura income**
  (stacking). Costs: 5,000 / 25,000 / 125,000 / 500,000 / 2,500,000 /
  10,000,000 / 50,000,000 Aura. Rebirth NEVER deletes your Index, Luck,
  Dollars or brainrots.
- **Weather events (random, 60 seconds each):** the first buff arrives
  2–4 minutes after the server starts, then one buff runs for exactly
  60 seconds, then 3–5 minutes of calm **Basic (x1, no buff)**, then the
  next random buff — never the same buff twice in a row, never Basic as
  an event. Summer x4 (warm bright sky + glowing sun + ember motes),
  Rainy x6 (dim blue-grey + fast rain), Cold x8 (pale blue + falling
  snow), Gothic x10 (dark purple fog + rising wisps), Void x12
  (near-black sky + purple stars). Every brainrot rolled during a buff
  sells for that multiplier. Gothic and Void stay bright enough to play in.
- **Brainrot Index (6 tabs):** Basic, Summer, Rainy, Cold, Gothic, Void —
  37 slots each. A brainrot rolled during Summer unlocks only the Summer
  tab. Locked slots show "???"; unlocked slots show the name, rarity and
  Dollar value. A completed tab (37/37) grants a permanent +10% Aura
  income.
- **Sell Zone:** the gold pad in the south-west of the plaza. Hold E to
  sell your most valuable copy for Dollars (base value x its event
  multiplier), with a floating "+$..." popup. The base pedestal and the
  Backpack Tool update when a copy is sold.
- **Luck Altar:** the purple pad in the south-east. Buy **Meteor Luck**
  with Dollars (levels 1–5: $1,000 / $3,000 / $8,000 / $20,000 / $50,000)
  — each level adds +2% **Lucky Roll** chance (max 10%): a dice result
  jumps one tier up.
- **Friend buff:** every other player in the server gives you **+5% Aura
  income**, capped at +20% (4+ friends). Shown live in the HUD.
- **Aura Shrines:** stand inside a glowing shrine beam for +20 Aura/s.
  Clicking anywhere also farms +2 Aura a click.

## Two currencies

- **Aura** — earned from your base, shrines and clicks. Spent only on
  dice rolls and Rebirth.
- **Dollar ($)** — earned only by selling brainrots at the Sell Zone.
  Spent only on Meteor Luck at the Luck Altar.

## How it is built (zero external assets)

Everything is built in code — no `.rbxm` files, no asset IDs:

- `src/shared/BrainrotDatabase.luau` is the shared roster (37 characters,
  8 rarities, 6 weather events, spawn weights, Dollar values) plus the
  procedural 3D builder — every creature assembled from Parts,
  SpecialMesh shapes, WeldConstraints, ParticleEmitters and BillboardGui
  tags — and the **Custom Model Override** loader (see below). All 37
  builders are self-tested at server start.
- `src/server/WorldAndSystems.server.luau` builds the whole world at
  runtime with `Instance.new`: the checker floor (the starter Baseplate is
  destroyed at start), floating islands, the giant Moai head with pixel
  sunglasses, tilted Greek pillars, Aura Shrines, the 8-dice row, the 10
  personal bases (10 pedestals each), the Rebirth Altar, the Sell Zone,
  the Luck Altar, and the weather particle sheet — plus the server
  authority: leaderstats (Aura, Dollar, Luck, Unlocked, Rebirth), dice
  rolls (Rebirth-gated, Lucky Roll, visible tumble animation), Backpack
  Tools (one per copy, synced on join/respawn/roll/sale), passive base
  income (Rebirth + Index + Friend buffs), Rebirth (dice gate + base
  slots), the random 60-second event cycle, the Index (saved to DataStore,
  pcall-wrapped), selling and Luck.
- `src/client/BrainrotUI.client.luau` builds the full ScreenGui in code:
  animated Aura + Dollar counters, the weather banner with countdown,
  Dice panel (8 dice, prices, locks, ROLL buttons), Rebirth panel, the
  6-tab Index, the Luck shop, server-wide pull announcements, floating
  "+Aura" / "+$" popups, click-to-farm, and the Friend buff in the HUD.
- `src/server-tour/TourHelper.luau` drives the TOUR.json steps for reviewers.

## Custom models — use your own 3D models (Toolbox / .fbx)

The game is 100% playable with the procedural cast, but you can replace
any character's look with your own model:

1. In Roblox Studio, open the place and find
   **ReplicatedStorage → CustomModels** (an empty folder in the project).
2. Drag a model in from the Toolbox, or **Import** a `.fbx` file
   (Avatar → Import 3D), and move it into `CustomModels`.
3. Rename the model to the character's **exact** name, e.g.
   `Bombardiro Crocodilo`, and set its **PrimaryPart** (select the model →
   set PrimaryPart to its main body part in the Properties panel).
4. Play: the game now uses your model for that character (with the name,
   rarity and $ tag added automatically). Any name left out of the folder
   keeps its procedural model, so a half-filled folder still plays with
   zero errors.

## Publish (owner's steps, in Roblox Studio)

1. Open `game.rbxl` in Roblox Studio, **File → Publish to Roblox As…** a new
   experience, and set it **Public** once Roblox's age check, description,
   genre and content questions are done.
2. Confirm **Max Players = 10** in Game Settings → Places (the project
   file sets it, but double-check it shows 10 before publishing).
3. Put the make.fun play code in the experience's description (Creator
   Dashboard → Configure). The code was given to the account owner in chat.
4. Fill in `PLAY.json` with the published place's `place_id` and
   `universe_id`.
5. Take 4 screenshots in Studio (plaza + dice row, dice roll + base +
   backpack, index, rebirth/luck/event) into `screenshots/` — the first by
   name is the cover and must be the same picture as the experience's
   first thumbnail, uploaded with its icon on the Creator Dashboard and
   past Roblox's review.

## v7.6 — Roll UX + HUD fixes

From Yami's v7.5 playtest (4 screenshots, 4 complaints):

- **Result card on top:** rolling used to leave the dice panel open, so
  the result card appeared *behind* it and Yami never saw what he
  rolled. Now `showResult` hides every panel first and the card sits at
  ZIndex 50 — and the dice panel is no longer re-opened after a roll.
- **Rolling animation + character picture:** before the reveal, the card
  plays ~1.2s of dice-rolling (the die face cycles 1–6, random names
  flash, the card shakes a little), then reveals the result with the
  rolled character's 3D model spinning slowly in a ViewportFrame (built
  from the same `DB.BuildModel` the game uses).
- **No more face emoji:** the floating name tag above each brainrot used
  to show the face emoji (`o_o`, `^_^`…). It now reads
  `$Value  •  +X Aura/s` — the Aura/s is the character's rarity rate
  times the active event multiplier.
- **HUD layout:** the LOCK button moved above the DICE button (bottom
  left); the REBIRTH button is gone from the HUD entirely — to rebirth,
  walk to the Rebirth Altar in the plaza centre (its prompt still opens
  the rebirth panel). All five HUD buttons (DICE, LOCK, INVENTORY, INDEX,
  LUCK) are ~30% smaller so they cover less of the screen.
- **Rare mutations:** weather events (Summer, Rainy, Cold, Gothic, Void)
  no longer run every few minutes — first buff 4–6 min after start,
  then 5–8 min of Basic between cycles, and only ~25% of cycles get a
  buff at all. The weather bar shows "Basic x1" with the countdown
  during the long calm gaps.

## v7.6.6 — Result card visible + honest Aura/s

Yami asked twice: the roll result card's character was still invisible
(a dark box — the v7.6.2 ViewportFrame fix was reverted when v7.6.4 went
back to v7.6.1), and the displayed Aura/s did not match how fast Aura
actually climbs.

- **Result card (v7.6.2 fix, re-applied):** card 360x360 fully opaque +
  UIStroke; ViewportFrame 160x160 with a bright sky background
  (150,190,255) + gradient, white LightColor, LightDirection
  (-0.5,-1,-0.5), Ambient 0.8; camera closer (1.8x) so the model fills
  the frame; labels shifted down to fit. Plus the v7.6.3 safety: the
  card position resets at the start of showResult so a cancelled roll
  can never leave it off-centre.
- **Aura/s, honest (root causes found in code, not guessed):**
  1. *Stale HUD (the +5/s Yami saw):* rolling via the 3D die (hold E)
     fires "RollResult" to the client, and that handler showed the card
     but never re-synced state — so the HUD rate froze at the old value
     while the server already paid for the new brainrot. The panel ROLL
     button did re-sync; the 3D-die path did not. Fixed: the RollResult
     handler now re-syncs (same 0.2s delay as the panel path). Selling
     and stealing also never re-synced — the server now fires "Cash" on
     a sale, on a steal deposit (thief), on the victim losing a copy,
     and on a carry being returned.
  2. *Shrine omitted from the display:* the server tick pays +20 Aura/s
     (x multiplier) while standing in a Shrine, but the client's
     preview never counted it — and the dice sit right next to the
     shrines, so Yami rolls while standing in one. Fixed: the client
     mirrors the shrine positions, checks the player's position live,
     and adds the +20 before the multiplier — exactly like the tick.
     The "+X/s" label is now re-computed every second (no server call),
     so it tracks walking in/out of a Shrine live.
  3. *Per-name rates now post-multiplier:* pedestal labels, model tags,
     the result card and inventory rows show base rate x the player's
     income multiplier (Rebirth/Index/Friends) — the rate a brainrot
     REALLY pays — instead of the bare rarity rate. The HUD total is
     (sum of distinct base rates + Shrine) x multiplier, exactly what
     the server pays per second. Income SIZE is unchanged (no nerf /
     buff): only the displayed numbers now match reality. Example:
     Trulimero Trulichina x2 + Pipi Popcorn x1 (all Common 5/s) =
     HUD +10/s and Aura +10 per second (solo, Rebirth 0, no Shrine).

## v7.1 — hardening: never a silent empty screen

A playtest showed the world built but the UI totally missing, with no
visible error anywhere. v7.1 makes that impossible to miss:

- **World build in sections:** each of the 13 world sections (floor,
  border, spawn, islands, Moai, pillars, shrines, altar, weather, shops,
  dice row, bases) runs inside its own `pcall` — one bad section warns
  and is skipped, the rest still builds, and `PlayerAdded` is always
  connected.
- **Client error label:** the ScreenGui + a big red **"⚠️ SERVER TIDAK
  MERESPONS"** label are built before any wait. Every wait for the
  server (Remotes, leaderstats, Aura, Dollar) has a 10-second timeout
  that SHOWS the label and reports to the server, instead of hanging
  silently forever.
- **Leaderstats always exist:** joining always creates leaderstats
  first; the rest of the join setup (save load, base claim, Tools) is
  pcall-wrapped.
- **ClientError remote:** the client reports its timeouts to the server
  log, so a silent client hang leaves a trace in Output too.

**Check you opened the right file:** every build is also named
`game.rbxl`, so Downloads fills up with look-alikes. Before opening,
check the file is the newest download and its size matches the size
announced in chat when the file was sent. If two files have the same
name, sort Downloads by date and delete the old ones.

**If the UI is still missing:** open **View → Output** in Studio and
copy the red error lines (they name the file + line), and confirm the
file size — that is what the fix needs.
